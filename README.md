# 算法练习簿 · algo-practice

一个可以直接打开 HTML 使用的算法学习工作台。按专题推进，自由安排日期，支持同一道题多次练习，每题保留一份 Markdown 笔记。

- 内置 16 个专题、96 个解法小类、140 道题，可自行管理题目和分类。
- 记录实际练习与掌握程度，查看日历、练习历史和复习参考。
- Markdown 笔记、专题文档、题目链接与动画链接。
- 浏览器自动保存，完整 JSON 备份与恢复。
- 无后端、无运行时第三方依赖，可离线使用，也可由 Nginx 托管。

## 使用

下载项目后，用常用浏览器打开 [刷题工作台.html](刷题工作台.html)。文件名和位置建议保持固定，升级前先导出备份。

详细操作见 [使用说明](刷题工作台使用说明.md)，题库整理见 [高频题型学习路线](力扣高频题型学习路线.md)。题库顺序是学习建议，并非官方面试频次排名。

## 开发与构建

构建使用 Python 3 标准库，测试使用支持 `node:test` 的 Node.js，不需要安装 npm 依赖。在项目根目录执行：

```sh
python3 刷题工作台源码/build.py
node --test 刷题工作台源码/*.test.js
```

修改 `刷题工作台源码/` 内的文件后重新构建；根目录 HTML 是生成的交付文件。

```sh
python3 刷题工作台源码/build.py --web
```

这会同时生成本地 HTML 和用于部署的 `dist/index.html`，两者内容一致。`dist/` 不纳入 Git，部署时重新构建即可。

## Nginx 部署

构建后只发布 `dist/` 目录。配置示例和数据迁移步骤见 [部署说明](deploy/README.md)。现有功能可以直接作为静态网站运行，不需要增加后端。

## 数据保存在哪里

题库修改、练习记录、笔记和专题文档保存在当前浏览器的 `localStorage` 中，不会写回源代码、GitHub 或 Nginx 服务器。仓库内只包含默认题库、程序及学习资料，不附带浏览器里的个人学习数据。

从本地文件改用网站、换域名、HTTP 改为 HTTPS，或更换浏览器和设备时，需要先导出完整 JSON，再到目标页面导入；导入会替换目标页面的数据。多设备自动同步需要另行开发服务端存储。

个人 JSON 备份请保存在仓库外，或根目录的 `backups/` 中；该目录已加入忽略规则。
